# CWE-863 越权/缺鉴权 微评分表

## 高风险模式
- 资源 id 直接来自路由/请求且未校验属主
- 管理操作仅靠前端隐藏入口
- API 路由漏挂鉴权中间件/注解

## 安全惯用法
- 对象级校验：属主/租户/角色三重核对
- 集中式鉴权中间件 + 路由清单对账
- 幂等敏感操作的二次确认服务端校验

## 伪消毒器（看似净化，实则可绕过——误判重灾区）
- 仅验证登录（认证≠授权）
- id 加密/混淆当鉴权
- 鉴权在 controller 某分支缺漏（if 提前 return）

## 引导问题（依次回答后再下结论）
1. 污点数据的真实来源是什么？是否攻击者可控？
2. 从入口到危险点之间有哪些净化/校验？对照上方伪消毒器清单逐条排查。
3. 该路径是否真实可达（挂在有效路由/入口之后，且配置启用）？
