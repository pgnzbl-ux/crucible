# CWE-918 SSRF 微评分表

## 高风险模式
- 用户输入构造出站 URL（fetch/requests/HttpURLConnection）
- webhook/导入/预览类功能请求任意 URL
- 重定向跟随开启且目标可被控制

## 安全惯用法
- 协议与主机白名单（https + 允许域）
- 解析后校验 IP 非内网段（含 DNS 解析结果）
- 独立出口 + 禁止重定向或逐跳校验

## 伪消毒器（看似净化，实则可绕过——误判重灾区）
- 仅校验域名文本（DNS rebinding 换 IP）
- 黑名单 127.0.0.1 但漏 0.0.0.0/169.254.169.254/IPv6
- 先请求再校验响应内容

## 引导问题（依次回答后再下结论）
1. 污点数据的真实来源是什么？是否攻击者可控？
2. 从入口到危险点之间有哪些净化/校验？对照上方伪消毒器清单逐条排查。
3. 该路径是否真实可达（挂在有效路由/入口之后，且配置启用）？
