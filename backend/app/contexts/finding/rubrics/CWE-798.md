# CWE-798 硬编码密钥 微评分表

## 高风险模式
- 源码/配置中硬编码 API key、密码、token、私钥
- 测试密钥与生产密钥同库
- 注释中留有真实凭据

## 安全惯用法
- 环境变量/密钥管理服务注入
- 示例文件用占位符（YOUR_API_KEY）
- .gitignore 排除本地密钥文件

## 伪消毒器（看似净化，实则可绕过——误判重灾区）
- 标注 TODO/示例就当无害
- 密钥已 rotate 但旧值仍在 git 历史
- base64/obfuscate 编码后的密钥

## 引导问题（依次回答后再下结论）
1. 污点数据的真实来源是什么？是否攻击者可控？
2. 从入口到危险点之间有哪些净化/校验？对照上方伪消毒器清单逐条排查。
3. 该路径是否真实可达（挂在有效路由/入口之后，且配置启用）？
