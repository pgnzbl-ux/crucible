# CWE-502 反序列化 微评分表

## 高风险模式
- pickle.loads/yaml.load(非 safe)/Java ObjectInputStream 接收外部数据
- session/缓存/base64 载荷直接反序列化
- JWT alg=none 或未验签先解码信任

## 安全惯用法
- JSON 等结构化格式 + schema 校验
- yaml.safe_load
- 签名验证在解析之前(JWT 锁定算法白名单)

## 伪消毒器（看似净化，实则可绕过——误判重灾区）
- 解析后再校验字段（ gadget 在解析时已触发）
- 异常包装掩盖反序列化入口
- 数据来自内部服务就当可信边界

## 引导问题（依次回答后再下结论）
1. 污点数据的真实来源是什么？是否攻击者可控？
2. 从入口到危险点之间有哪些净化/校验？对照上方伪消毒器清单逐条排查。
3. 该路径是否真实可达（挂在有效路由/入口之后，且配置启用）？
