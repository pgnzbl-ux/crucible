# CWE-639 IDOR / 对象级越权 微评分表

## 高风险模式
- 路径/查询/Body 中的对象 id 直接用于 ORM/DAO 查询
- 查询未绑定当前用户 / 租户 / 组织条件
- 同资源读写接口鉴权强度不一致

## 安全惯用法
- 查询 WHERE 含 owner_id / tenant_id = 会话身份
- 集中式 policy（Pundit/CASL/自定义 guard）在返回前强制
- 存在性神谕：越权应 403/404，不得回显他人数据

## 伪消毒器
- 仅验证已登录（认证≠对象级授权）
- id 用 UUID/加密当鉴权
- 前端隐藏或仅校验「id 格式」

## 引导问题
1. 对象 id 是否攻击者可控？来自哪一入参？
2. 取数前是否用会话身份做了 ownership/租户校验？校验在查询内还是查询后？
3. 该 handler 是否挂在有效鉴权链之后且配置启用？
